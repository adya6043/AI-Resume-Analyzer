# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer built using the **MERN Stack** that analyzes resumes, calculates ATS scores, extracts technical skills, generates interview questions, and provides AI-powered career feedback using **Google Gemini AI**.

---

## ✨ Features

* 🔐 JWT Authentication (Register/Login)
* 📄 Upload Resume (PDF)
* 🤖 AI Feedback using Google Gemini
* 📊 Resume Score Calculation
* 🎯 ATS Compatibility Score
* 💡 Automatic Skill Extraction
* ❓ AI Generated Interview Questions
* 📜 Resume History
* 🗑 Delete Uploaded Resume
* ☁ MongoDB Atlas Integration

```bash

```

## 🔑 Environment Variables

Create a `.env` file:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```
